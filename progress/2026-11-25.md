## 今天真正学到的三件事

- **程序 = 状态机**：CPU 的「状态」就是寄存器 + PC，每拍按指令改一次状态。
- **循环 = 改写 PC**：`BNER0` 之所以能循环，只是因为它能把 PC 改回前面的地址。
- **抽象阶梯**：晶体管 → 门 → 加法器 → ALU → 数据通路 + 控制器 → CPU。每一级都把下面藏起来。

## 下午补充：Logisim 真的连上了

用户说本机 Logisim 可用，给了快捷方式 `D:\桌面\logisim-evolution.lnk`。排查结果：

- 实际程序：`D:\Program Files\logisim-evolution\logisim-evolution.exe`
- 版本：**Logisim Evolution 4.0.0**，自带 OpenJDK 21.0.4（系统 PATH 里没有 java，但 exe 自带 runtime）
- jar：`app\logisim-evolution-4.0.0-all.jar`，主类 `com.cburch.logisim.Main`
- 命令行可用：`-v` / `-h` / `-t stats`（无头加载）/ `-w <电路> <向量文件> <项目文件>`（测试向量）/ `-n`（格式转换）

**做成的实验**：`labs/F02-half-adder/`，半加器（XOR 出 S、AND 出 C）。

- 生成 `.circ`（4.x XML 格式：Gate 的 `loc` 是输出引脚，`size=30` 时输入在 `(x-30, y±10)`）
- `-t stats` 加载成功：4 Pin + 1 AND + 1 XOR = 6 元件
- `-w main vectors.txt half_adder.circ` → **`Passed: 4, Failed: 0`**

**踩到的坑（已写进实验 README）**：Logisim 里交叉导线默认不相连，只有端点落在另一条线上或显式加连接点才连。布线时 A 的横线和 B 的竖线在 (230,230) 交叉，测试能过正说明没短接。

**能力边界要说清**：不能实时操控 GUI 拖元件，但能生成 `.circ`、写测试向量、用命令行跑无头仿真读回结果。用户打开 `.circ` 自己拨开关观察，我负责生成和验证——这个配合方式挺顺。
