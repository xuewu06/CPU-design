# F01 · 4 指令最小 CPU 模拟器

对应 F4（状态机模型）+ F5（数列求和处理器）。**零依赖**，只要装了 Python 3。

## 跑起来

```bash
cd labs/F01-scpu
python scpu.py
```

Windows 上如果 `python` 不识别，试 `py scpu.py` 或 `python3 scpu.py`。

只看结果：

```bash
python scpu.py --quiet
```

正确输出应该是：

```
共执行 34 条指令，OUT 输出 = [55]
1 + 2 + ... + 10 = 55
```

## 它是什么

一台只有 **4 条指令**的 CPU，用软件模拟：

| 指令 | 作用 |
|---|---|
| `LI rd, imm` | 把立即数装进寄存器 |
| `ADD rd, rs1, rs2` | 两个寄存器相加，结果写回 rd |
| `BNER0 rs, target` | 若 rs ≠ 0，把 PC 改成 target（实现循环） |
| `OUT rs` | 输出寄存器的值 |

指令集与「一生一芯」F 阶段 sCPU（`add` / `li` / `bner0` / `out`）对齐，任务也一样：算数列求和。
区别只是**用 Python 模拟，而不是用 Logisim 画电路**——概念完全一致，门槛低很多。等概念稳了，再到 E 阶段用 Verilog 把它变成真正的硬件描述。

## 程序怎么读

```asm
LI    r1, 0        # r1 = sum
LI    r2, 10       # r2 = i，从 10 倒数
LI    r3, -1       # r3 = 步长
ADD   r1, r1, r2   # sum += i     <- 循环体从这里开始（pc=3）
ADD   r2, r2, r3   # i -= 1
BNER0 r2, 3        # i 还没到 0？跳回 pc=3
OUT   r1           # 输出 55
```

`BNER0` 是整套东西里最关键的一条：它**改写 PC**，于是状态机跳回去再来一遍。
循环不是什么魔法，就是「一个寄存器还没归零 + 一条能改 PC 的指令」。

## 对照状态机模型（F4）

跑 `python scpu.py`，看打印出来的每一行，把这张表对上：

| 状态机要素 | 代码里的位置 |
|---|---|
| 当前状态 | `cpu.reg`（4 个寄存器）+ `cpu.pc` |
| 输入 | `cpu.program[cpu.pc]` |
| 次态逻辑 | `CPU.step()` 里的 if/elif 分支 |
| 下一状态 | 被更新的 `reg` 和 `pc` |
| 一拍 | `cpu.step()` 调用一次 |
| 停机 | `pc >= len(program)` |

**特别注意 `r0`**：`step()` 末尾强制 `self.reg[0] = 0`。RISC-V 的 `x0` 也是恒零寄存器，好处是「和 0 比较」「清零」都能复用普通指令，不用专门加硬件。

## 为什么用 Python 而不是 Logisim

官方 F2/F5 用 Logisim 画电路，能直观看到门和连线，非常好。但对完全零基础的人来说，第一道墙往往是「装软件 + 搞懂画图界面」，而不是 CPU 本身。

这里先用 30 行能跑的代码把**取指 → 译码 → 执行 → 写回 → 更新 PC** 这个闭环建立起来。等你能在不看笔记的情况下讲清楚这五步，再切到 Logisim / Verilog，就是从「理解」到「换一种表达方式」，不再是同时啃两个陌生东西。

## 练习

按难度递进，建议至少做完前三个：

1. **改数**：把 `LI r2, 10` 改成 `LI r2, 100`，预期结果 5050。跑一下验证。
2. **改和**：让程序算 `1² + 2² + ... + 10²`（385）。提示：需要再想办法做乘法，或者干脆加一条 `MUL` 指令到 `step()` 里。
3. **故意弄坏**：把 `BNER0 r2, 3` 的 `3` 改成 `4`，观察输出变成什么，用 [docs/00](../docs/00-如何科学地提问.md) 的模板写一份提问。
4. **加指令**：实现 `SUB rd, rs1, rs2`，然后用它重写递减（不再需要 `r3 = -1`）。
5. **防死循环**：现在用 `cpu.steps < 1000` 兜底。想想如果程序真的需要跑 2000 步会怎样？真实 CPU 靠什么保证不会永远跑下去？
6. **讲一遍**：合上笔记，向一个完全不懂的人解释「为什么改 PC 就能实现循环」。讲不顺的地方，就是你还没真懂的地方。
